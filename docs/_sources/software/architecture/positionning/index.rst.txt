Positionning
========================

Measuring Altitude
------------------------

We combine two data sources from the IMU to measure the altitude :

- The barometer for "long term" accuracy (~5m of noise and up to 15m of drift over 1h depending on weather conditions)
- The accelerometer for short term variations
 
The idea is to integrate the accelerometer over time and to correct its drift using the noisy but accurate barometer readings.

.. note::
    The barometer must be zeroed before takeof

Algorithm
________________________

We use two buffers that store the last 30 seconds of sensors data with time stamps :

- **Accelerometer buffer** : stores the height calculated by integrating the accelerometer readings.
- **Barometer buffer** : stores the height measured with the barometer

The altitude is calculated as follows : 

.. math::
    H(t, H_0, S_0) = A(t) + H_0 + S_0 * (t - t_0)

Where 

- :math:`A(t)` is the height at t calculated by interpolating the Accelerometer Buffer  
- :math:`H_0` is a correction term used to compensate height drift from the accelerometer
- :math:`S_0` is a correction term used to compensate speed drift from the accelerometer
- :math:`t_0` is the first timestamp of the Accelerometer Buffer

**Calculating the correction terms**

We use a simple least square regression to find the values of :math:`H_{correction}` and :math:`S_{correction}` that best match the data in the **Barometer Buffer**

We try to minimize the following function : 

.. math::
    F(H_0, S_0) = \sum_{i} (H(t_i, H_0, S_0) - B_i)^2

Where 

- :math:`H(t)` is the height function described previously
- :math:`B_i` is the ith height of the Barometer Buffer
- :math:`t_i` is the ith timestamp of the Barometer Buffer

The function can be rewritten as follows : 

.. math::
   F(H_0, S_0) = \alpha H_0^2 + \beta S_0^2 + \gamma H_0S_0 + \delta H_0 + \epsilon S_0 + \zeta

Where 

- :math:`\alpha = N` (the number of samples in the Barometer Buffer)
- :math:`\beta = \sum_{i}(ti - t_0)^2`
- :math:`\gamma = 2 \sum_{i}(ti - t_0)`
- :math:`\delta = 2 \sum_{i}(A(ti) - Bi)`
- :math:`\epsilon = 2 \sum_{i}(t_i - t_0)(A(ti) - Bi)`
- :math:`\zeta = \sum_{i}(A(ti) - Bi)^2`

We want to find :math:`H_0` and :math:`S_0` so that

.. math::
    \frac{dF(H_0, S_0)}{dH_0} = 0 \\
    \frac{dF(H_0, S_0)}{dS_0} = 0

The first equation gives us 
    
.. math::
    2 \alpha H_0 + \gamma S_0 + \delta = 0

The second equation gives us

.. math::
    2 \beta S_0 + \gamma H_0 + \epsilon = 0

When solving this system of equations we get : 

.. math::
    H_0 = \frac{\gamma\epsilon - 2\delta\beta}{4\alpha\beta - \gamma^2} \\
    S_0 = \frac{\gamma\delta - 2\alpha\epsilon}{4\alpha\beta - \gamma^2}
